Forma · Base

Suavidad con sombra-susurro

Rea usa una escala 4pt, radios generosos y bordes sutiles. La profundidad se apoya en superficie, borde fino, tamano, color contextual y agrupacion; la sombra es un susurro (shadows[1] tarjetas, [2] CTA/hojas) que solo redondea, nunca dramatiza.

Pantalla

El contenido mobile es edge-to-edge. Cada componente define su propio padding interno.

Tacto

Minimo 44pt. Controles comunes usan 40, 48 o 56 segun importancia.

Safe area

App bar y tab bar respetan notch, home indicator y gesto inferior del sistema.

Uso mobile

  • 4-8 separa icono/texto o elementos muy relacionados.
  • 12-16 es ritmo normal dentro de controles y listas.
  • 20-24 separa grupos dentro de una seccion.
  • 32-48 separa secciones mayores o bloques de decision.
  • 64 se reserva para respiracion superior/inferior de pantallas clave.

03 · Contenedores mobile

Espacio segun tarea

Rea no define una plantilla unica para todas las vistas. Cada pantalla usa la estructura que corresponda a su objetivo, manteniendo los mismos tokens de espacio, radios y tacto.

Full width

Hero, calendario y tab bar pueden ocupar todo el ancho disponible. Su respiracion vive dentro del componente.

Contenido denso

Listas, formularios y metricas usan padding interno propio para conservar lectura y targets tactiles.

Superposiciones

Bottom sheets y dialogs respetan safe area, conservan contexto y se elevan con sombra-susurro (shadows[2]), nunca con un drama de profundidad.

Elemento Espacio Criterio
App bar 16px horizontal + safe area superior Debe separar controles sin crear un marco artificial.
Hero 18-24px interno El borde inferior curvo pertenece al componente, no a la pantalla.
Calendario 14-16px interno La grilla se mantiene compacta y tactil en 375px.
Lista 14-16px por fila Separar filas por hairline y agrupacion, no por sombra.

Tab bar 60px nominal + safe area inferior El borde superior define separacion; no se usa elevacion.
