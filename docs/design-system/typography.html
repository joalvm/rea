02 · Uso por contexto

Jerarquia para pantallas mobile

Hero de fase

  • display para numero de dia o estado central.
  • subhead para fase; confiabilidad usa badge compacto.
  • body para mensaje breve, maximo 2 lineas utiles.

App bar y tab bar

  • App bar usa h3 o title segun longitud.
  • Tab label usa caption, maximo una palabra.
  • Activo se diferencia por color e icono, no por texto mas grande.

Formularios

  • Label visible con subhead o caption.
  • Input usa body; placeholder nunca reemplaza label.
  • Error usa footnote con icono y texto accionable.

Datos y metricas

  • Cifras grandes usan Quicksand y numeros tabulares si hay comparacion.
  • Unidades y metadata usan caption o footnote.
  • No esconder contexto: "Dia 12" mejor que solo "12".
03 · Accesibilidad

Lectura real en mano

Regla Contrato Motivo mobile
Line-height Entre 1.18 y 1.5 segun variante. Evita bloques densos en pantallas cortas.
Dynamic Type Textos criticos no deben truncarse. La usuaria puede tener fuente del sistema aumentada.
Longitud Mensajes de UI maximo 2 lineas antes de detalle. Reduce friccion en registro diario.
Contraste Texto siempre usa roles semanticos del tema. El switch dark/light debe conservar lectura sin duplicar pantallas.
