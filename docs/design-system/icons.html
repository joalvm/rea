Iconos · Base

Iconografia de trazo Lucide

Rea usa Lucide Icons como set base para navegacion, acciones y estados. Esta documentacion HTML los renderiza desde CDN Lucide con data-lucide. En check-in, el icono es la identidad del paso; los numeros solo pueden quedar como progreso secundario o valor interno.

Estilo

24px viewBox, trazo 2, extremos redondeados, sin rellenos complejos.

Color

Hereda currentColor. Nunca fijar un hexadecimal dentro del SVG.

Accesibilidad

Decorativo: oculto. Accionable: label accesible y area tactil minima 44pt.

04 · Opciones marcables

Escalas con lenguaje humano

Las preguntas graduables del check-in usan iconos y etiquetas humanas. Registrar estres, dolor, animo o energia debe sentirse como elegir un estado reconocible, no como completar una escala abstracta.

  • CalmaEstado bajo o sin tension.
  • LeveMolestia presente pero manejable.
  • TensionSe nota en cuerpo o animo.
  • AltaInterfiere con el dia.
  • Muy altaIntensa y sostenida.
  • LimiteRequiere pausa o apoyo.
05 · Reglas

Tamanos y estados

Token Valor Uso
iconXs 16px Badges, helpers, checks internos.
iconSm 18px Botones con texto, inputs, listas compactas.
iconMd 22px Tab bar, listas principales, cards.
iconLg 28px Empty states, headers de modulo, ilustracion funcional.
iconXl 36px Solo momentos de onboarding o estado vacio importante.

En app nativa se usa lucide-react-native. Si Lucide no cubre un sintoma, crear icono propio con la misma geometria: viewBox 24, stroke 2, extremos redondeados, sin relleno y exportado para currentColor.
