Color · Proposito

Firma celeste, no decoracion

Aqua Rea es la firma emocional de la app: cercana, luminosa y confiable. En mobile debe guiar accion y contexto sin saturar pantallas pequenas.

Decision principal

aqua.300 = #7CD9F9 es marca. En light funciona mejor como superficie o CTA, no como texto pequeno.

Regla de contraste

Texto sobre primary usa onPrimary = #062633. Blanco sobre #7CD9F9 no se usa para texto pequeno.

05 · Reglas

Uso correcto en app mobile

Hacer
  • Usar roles theme.colors.* y theme.phases.*.
  • Diferenciar observado/estimado por forma, patron y texto.
  • Reservar colores intensos para feedback o fase activa.
  • Usar logo #7CD9F9 en light y blanco en dark.
Evitar
  • Usar fases como decoracion sin significado.
  • Combinar rojo/rosa con lenguaje alarmista.
  • Usar grises slate genericos fuera de Mist.
  • Crear componentes con hexadecimales sueltos fuera del theme.
